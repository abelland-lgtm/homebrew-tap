# abelland-lgtm/homebrew-tap

Homebrew formulas for [abelland-lgtm](https://github.com/abelland-lgtm)'s projects. They work on macOS and Linux.

```sh
brew tap abelland-lgtm/tap
```

## Formulas

| Formula | Description | Install |
|---|---|---|
| [tbard](https://abelland-lgtm.github.io/tbard/) | Audiobook manager and listener for the terminal (installs mpv and ffmpeg too) | `brew install abelland-lgtm/tap/tbard` |

Update with `brew upgrade`.

## Maintenance

Each project's release workflow writes its formula in `Formula/` automatically on every release. Change the
project's workflow rather than editing the formulas here by hand.
