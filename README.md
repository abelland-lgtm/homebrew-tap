# abelland-lgtm/homebrew-tap

Homebrew formulas for [tbard](https://github.com/abelland-lgtm/tbard), an
audiobook manager and listener for the terminal.

```sh
brew install abelland-lgtm/tap/tbard
```

This installs mpv and ffmpeg too. `Formula/tbard.rb` is updated automatically
by tbard's release workflow; do not edit it by hand.
